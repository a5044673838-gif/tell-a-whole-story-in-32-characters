One Wi-Fi network name, 28 characters, that tells a whole story for
make.fun's "Tell a Whole Story in 32 Characters" bounty ($2): dad laid down
the law, the household conspired, and now there are three dogs. Pure Python
standard library, no network, fully deterministic.

## Run it

```
python3 main.py
```

Writes `entry.txt` to `/output` (`MAKEFUN_OUTPUT_DIR` overrides).
